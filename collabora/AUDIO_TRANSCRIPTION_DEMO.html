🎤 Boudica Audio Transcription Integration

1. Standalone UI Panel

Add the complete audio upload panel to any page:

<div id="audioPanel"></div>
<script>
const audio = new AudioTranscription();
const ui = new AudioUploadUI('audioPanel', audio);
</script>

Best for: Dashboard, dedicated transcription page

2. Chat Integration

Add microphone button to chat toolbar:

const audio = new AudioTranscription();
const chatAudio = new ChatWithAudioTranscription
('chatContainer', audio);

Best for: Talk integration, message input

3. Programmatic Usage

Use the service without UI:

const audio = new AudioTranscription();
const result = await audio.transcribeFile(
file, onProgress
);
console.log(result.transcript);

Best for: Custom integrations, automation

4. Talk Bot Integration

Automatic transcription in Talk rooms:

@boudica transcribe

Participants notified via email
with full transcript

Best for: Meeting recordings, voice calls

Installation & Setup

1. Include Scripts in HTML

<script src="js/audio-transcription.js"></script>
<script src="js/audio-upload-ui.js"></script>
<script src="js/chat-audio-integration.js"></script>

2. Ensure Whisper Service is Running

# Check if Whisper container is running
docker ps | grep whisper

# Or check service health
curl http://localhost:5000/health

3. Initialize in Your App

const audioTranscription = new AudioTranscription();

// Option A: Use pre-built UI
const ui = new AudioUploadUI('containerID', audioTranscription);

// Option B: Use chat integration
const chat = new ChatWithAudioTranscription('chatID', audioTranscription);

// Option C: Use programmatically
const result = await audioTranscription.transcribeFile(file);

4. Supported Audio Formats

WAV • MP3 • M4A • OGG • FLAC • AAC • WebM • Opus

5. Configuration

// Custom Whisper service URL
const audio = new AudioTranscription('https://your-domain.com:5000');

// Change max file size
audio.setMaxFileSize(1000); // 1GB

// Check service availability
const available = await audio.isServiceAvailable();

6. Talk Bot Command

In any Talk room, mention the bot to transcribe recordings:

@boudica transcribe

Bot will transcribe recent recordings and email all room participants with the transcript.
